# Labels and labeled jumps — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add label statements (`name@`) and labeled `break@`/`continue@`/`return@` jumps, plus the phi-predecessor fix they require.

**Architecture:** A label is an IR basic block. The grammar gains one `statement` alternative; the AST builder turns `LabelDefinition` statements and the `*_AT` jump tokens into nodes; the checker scopes labels per function (forward and backward references via a body pre-scan); the emitter reserves a block per label and branches to it.

**Tech Stack:** Kotlin 21, ANTLR 4.13 (Kotlin grammar), hand-rolled LLVM-IR text, LLVM-MOS, JUnit 5, VICE (`x64sc`) for integration tests.

**Spec:** `docs/superpowers/specs/2026-11-21-labels-design.md`

## Global Constraints

- Error messages are exactly: `Unknown label X`, `Label X already defined` (X = the label name).
- `return@0xea31` (address form) keeps working, pinned by `ReturnAtGrammarTest`; the `FunDecl.returnAt` list collects **address sites only** (drives the `interrupt` attribute drop, `ModuleEmitter.kt:76`).
- Labeled jumps and unlabeled `break`/`continue` semantics for loops are unchanged; unlabeled `break` still throws `error("break outside a loop")` in the emitter.
- A label name may be any identifier, including keyword spellings (`var@` / `break@var`); nothing is rejected for names.
- Commits: conventional style with a scope (`feat(grammar):`, `feat(ir):`, `docs:` …), one commit per task.
- Full test command: `./gradlew test` (integration tests need `x64sc` on `PATH`; it is installed).
- ANTLR regeneration: `./gradlew generateParser` (also runs implicitly on `compileKotlin`).

## Review Focus

Input classes the spec implies but no task's tests would obviously cover; each line's test is added to the owning task.

1. **Interrupt handler with a `return@<label>` site keeps the `interrupt` attribute** (only address sites drop it) — the emitted IR must still carry `attributes #0 = { "interrupt" }` and the handler's plain exit stays `rti`. → Task 2, IR tests.
2. **A `when`-expression branch that ends in a label** produces its value in the label's block — the phi at the `when` end block must name that block (the `whenFlow` side of the phi fix; the if-side is tested directly). → Task 2, IR tests.
3. **An `if`-expression branch that leaves through a labeled jump** produces no value from that side (the existing "branch leaves through a terminator" rule, now with a label terminator); the other side's value is used, no phi from the jumping side. → Task 2, IR tests.
4. **A label whose name collides with an internal block name** (`loop`, `body`, `entry`, `bb1`) still resolves — the `reserveLabel` fallback renames one side, and the jump must target the reserved name the pre-scan recorded. → Task 2, IR tests.
5. **An unlabeled `continue` inside a loop whose body starts with a label** targets the loop's condition block, not the label (the label does not bind the loop). → Task 2, IR tests.

Add a pre-scan (the walk from the spec's Semantics — `FunctionLit` is a boundary):

```kotlin
private fun collectLabels(stmts: List<Stmt>): Set<String> {
    val out = mutableSetOf<String>()
    fun visit(s: Stmt) {
        when (s) {
            is LabelStmt ->
                if (!out.add(s.name)) throw SemaException("Label ${s.name} already defined")
            is BlockStmt -> s.body.forEach { visit(it) }
            is IfStmt -> { s.then.forEach { visit(it) }; s.otherwise.forEach { visit(it) } }
            is WhileStmt -> s.body.forEach { visit(it) }
            is WhenStmt -> s.entries.forEach { it.body.forEach { visit(it) } }
            is ExprStmt -> visitLabelsInExpr(s.expr)
            is ReturnStmt -> s.value?.let { visitLabelsInExpr(it) }
            else -> Unit
        }
    }
    fun visitLabelsInExpr(e: Expr) {
        when (e) {
            is IfExpr -> { e.then.forEach { visit(it) }; e.otherwise.forEach { visit(it) } }
            is WhenExpr -> e.entries.forEach { it.body.forEach { visit(it) } }
            else -> Unit
        }
    }
    stmts.forEach { visit(it) }
    return out
}
```
